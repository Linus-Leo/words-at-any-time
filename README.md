# FloatingWordBall

一个安静、常驻桌面的悬浮背单词工具。平时是一张只显示单词的长方形胶囊，鼠标移上去展开释义和“认识 / 模糊 / 不认识”三个按钮；单击胶囊可固定释义，再单击一次解除固定。今天点过“认识”的词当天不再出现，模糊和不认识的词继续循环；不认识的词会自动收进“我的单词本”。释义会从有道补充更完整的中文义项和词形，并按公开语料词频标出 1–3 颗重要度星标。提供青绿、湖蓝、琥珀、靛紫四套配色，支持按顺序、自选单词和自定义单词本三种背词方式。

## 快速开始

要求：Windows 10/11，Python 3.10+（本项目已在 Python 3.11 + PySide6 6.12 上验证）。

```powershell
cd "C:\path\to\FloatingWordBall"
py -3.11 -m pip install -r requirements.txt
py -3.11 main.py
```

也可以双击项目根目录的 `launch_silent.bat`；它通过 `pythonw` 启动，不保留控制台窗口。`run.bat` 保留用于查看启动错误。

词库与重要度数据已随项目放在 `vocab/` 和 `importance.json` 中，正常使用无需联网或重新下载。内置词库来自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT），生成方式和许可信息见 [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)。`vocab_fetcher.py` 仅作为旧版联网下载兼容入口保留。

界面不显示音标，也不伪造音标数据；详细义项和词形来自有道词典，失败时回退到本地词库。

## 操作

| 操作 | 效果 |
| --- | --- |
| 悬停 | 展开释义和“认识 / 模糊 / 不认识”按钮 |
| 移开（未固定） | 收起释义，只保留单词 |
| 单击胶囊 | 固定释义；再单击一次解除固定 |
| 点击“认识” | 记录评级；该词当天不再出现 |
| 点击“模糊” | 记录评级；该词排到后面第 2 位，继续出现 |
| 点击“不认识” | 记录评级；该词排到后面第 1 位，并自动加入“我的单词本” |
| 点击“不认识”右侧的立方体加号 | 选择加入“我的单词本”、已有自定义本，或当场新建单词本 |
| 左键拖动胶囊 | 移动位置，自动记忆 |
| 拖动左/右/上/下边缘或四角 | 调整胶囊大小；这是唯一改变大小的方式 |
| 松手靠近屏幕左右边缘 | 进入侧边隐藏；胶囊缩成一条贴在屏幕边的窄条，鼠标移到窄条上自动展开 |
| 滚轮 | 向下滚下一个词，向上滚上一个词 |
| 双击单词区域 | 立即换词 |
| 左键点击喇叭 | 先播放有道在线发音，失败时用系统语音 |
| 托盘右键 → 单词本… | 按顺序选起点，或自选单词；设置每天循环个数 |
| 托盘右键 → 我的单词本… | 查看、新建、重命名、删除、移出单词；开始背某个本子 |
| 托盘右键 → 学习日历… | 按月查看每天认识 / 模糊 / 不认识的次数 |
| 托盘右键 → 颜色主题 | 青绿、湖蓝、琥珀、靛紫 |
| Alt+Q | 老板键：隐藏/恢复胶囊 |
| Alt+W | 鼠标穿透开关；穿透只在本次运行有效，托盘双击、托盘菜单、Alt+W 或 Esc 都可恢复 |
| Esc | 依次关闭鼠标穿透 → 取消固定并收起 → 收起 |
| 托盘双击（穿透时） | 直接关闭鼠标穿透，不会误触老板键 |
| 托盘右键 → 关闭鼠标穿透 | 穿透时从托盘菜单恢复鼠标操作 |
| 托盘右键 → 恢复今日已认识的单词 | 清空今天的认识集合，让这些词重新进入队列 |
| 托盘右键 → 重置胶囊大小与位置 | 回到默认尺寸和屏幕右上方，并取消侧边隐藏 |
| 托盘双击（未穿透时） | 隐藏/恢复胶囊 |

## 单词本与每日进度

- **按顺序背**：在词库列表里选中一个起点，程序从该词起按词库顺序取“每天循环个数”个词。
- **自选单词**：勾选想循环的词；每日循环个数从勾选词中按顺序取用。
- **我的单词本**：点“不认识”时自动收集当前词；同一个词不会重复加入。立方体加号可以把当前词加入其他自定义本。
- 每日循环个数范围 1–1000；跨日会从当天队列开头重新循环，并重置当天的认识/模糊/不认识计数。
- 当天点过“认识”的词会写入 `study.known_today`，在当天重建队列时被过滤；第二天自动清空。
- 学习日历读取 `study.history`，按日期显示三档点击次数。
- 单词本保存在同目录的 `wordbooks.json`；学习计划、游标和当天进度保存在 `config.json`。

## 详细释义与重要度

- 显示当前词时，后台向有道词典 `jsonapi` 请求中文义项（最多 4 条）和词形变化（最多 5 条），追加在本地词库释义下方，不阻塞界面。
- 请求结果按词缓存在同目录的 `details_cache.json`（最多 900 条），下次遇到同一个词直接读取；断网、超时或解析失败时回退到本地词库的释义和短语。
- 三颗星表示词频重要度：基于 ECDICT 的 BNC/COCA 词频排名，排名 ≤3000 为三星，≤10000 为二星，其余或未收录为一星。星标只作学习优先级参考，不是考试大纲评级。
- `importance.json` 随项目提供，运行时无需联网；`main.py` 的 `STAR_THRESHOLDS` 控制分档，重新生成该文件即可调整。

## 配置

`config.json` 会在退出、换词库、移动、缩放、侧边隐藏、评级和修改单词本计划后自动保存。

| 键 | 说明 |
| --- | --- |
| `vocabulary` | `CET4` / `CET6` / `Kaoyan` / `TOEFL` |
| `scale` | 基础缩放，限制为 0.6–2.5；界面不再提供缩放菜单 |
| `opacity` | 胶囊不透明度，限制为 0.25–1.0 |
| `click_through` | 鼠标穿透开关；只在本次运行有效，保存时始终写回 `false` |
| `position` | `[x, y]`；为 `null` 时出现在主屏右上方 |
| `size` | `[w, h]`，胶囊展开后的记忆尺寸；`null` 表示默认 |
| `dock` | `left` / `right` / `null`；贴边后隐藏到屏幕侧面，只留约 20px 的窄条，鼠标移入即展开 |
| `theme` | `green` / `blue` / `amber` / `violet` |
| `study.mode` | `sequence` 按顺序 / `custom` 自选 / `book` 自定义单词本 |
| `study.start_index` | 顺序模式起点在词库中的下标 |
| `study.daily_count` | 每天循环的单词个数 |
| `study.custom_words` | 自选模式的单词列表 |
| `study.book` | 自定义单词本模式使用的本子名 |
| `study.cursor` | 当天队列中的当前位置 |
| `study.date` | 当天日期；跨日自动重置游标、认识集合和计数 |
| `study.known_today` | 今天已点“认识”的词，当天不再出现 |
| `study.counts` | 当天认识 / 模糊 / 不认识次数 |
| `study.history` | 按日期的历史计数，供学习日历读取 |
| `study.ratings` | 每个词最近一次评级 |

## 设计与实现

- 视觉固定锚点：深青 `#173B38` 配青柠 `#D6F56D` 的圆角长方形胶囊；单词、星级、释义和按钮都在胶囊内部，不使用独立释义卡。
- 词条层级为单词 → 三颗重要度星 → 中文义项 / 词形 → 三档按钮；固定时胶囊描边变为强调色，左侧还有一条细强调条。
- 胶囊有 252px 的最小宽度，按钮文字会随宽度缩字；“不认识”使用当前主题的危险色，鼠标悬停时按钮和喇叭都有反馈，超长单词用省略号收尾。
- 不设倒计时；换词由滚轮、双击或评级按钮触发，不以时间自动切词。
- 展开高度按当前宽度计算释义所需高度，再调整胶囊；最多显示 4 条中文义项、2 条搭配和 5 个词形，长释义不会被按钮或底边裁切。
- 单击、拖动、缩放、按钮和喇叭由主窗口统一命中测试；子控件对鼠标透明，避免拖动被 QLabel 吞掉。
- 新建单词本、日历和提示框统一通过 `present_dialog` 打开：强制 `WindowStaysOnTopHint`、应用级模态，并优先放在胶囊的左侧或右侧；两侧都放不下时再尝试上下位置，避免挡住胶囊。
- 尺寸只由鼠标拖边改变；滚轮不再缩放，避免误触改变布局。
- 发音在后台线程下载，不阻塞界面；临时音频播放后清理。Windows 离线降级调用系统 `System.Speech`，不要求管理员权限。
- Alt+Q / Alt+W 使用 Windows `RegisterHotKey`；被其他软件占用时不会崩溃，托盘菜单仍可完成同样操作。
- 鼠标穿透不跨重启持久化：`load_config` 和 `save_config` 都强制写回 `false`，避免下次启动无法点回窗口；开启时托盘会提示恢复入口。
- 影响可见状态的操作都有回转入口：穿透可关闭、今日认识可恢复、尺寸和位置可重置、固定可取消、Esc 可逐级退出。
- 词库路径、配置路径和界面状态都在本目录内，不使用注册表。

## 常见问题

- **点了鼠标穿透改不回去**：双击托盘图标，或托盘右键 → “关闭鼠标穿透”，也可以按 Alt+W 或 Esc。穿透只在本次运行有效，重启后会自动关闭。
- **Alt+Q / Alt+W 没反应**：快捷键被其他应用占用。打开托盘右键菜单，用“隐藏/显示”“关闭鼠标穿透”完成同样操作，或先释放快捷键冲突。
- **释义为什么比词库多**：详细义项和词形来自有道在线词典；没有网络或请求失败时会显示本地词库的释义和短语。
- **不想让程序联网**：在线发音失败会自动改用本机语音；词库文件已本地化。下载或更新词库需要访问 GitHub。
- **没有声音**：检查系统默认输出设备和已安装语音。Windows 朗读使用 `System.Speech`；如果系统没有可用语音，会提示离线发音失败，此时在线发音仍可正常工作。
- **释义没有展开**：把鼠标移到胶囊上，或单击胶囊固定；固定后移开鼠标也会保留释义。
- **单词今天不见了**：它已被标记为“认识”。当天不再出现，明天自动回到循环；学习日历里仍能看到今天的记录。
